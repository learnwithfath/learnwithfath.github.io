# Agentic Loop Lab

Repository latihan Minggu 1–3. Download dan clone `agentic-loop-lab.bundle` dari roadmap agar seluruh checkpoint branch tersedia.

```bash
npm test
npm run lab -- verify 01
```

- Minggu 1: duplicate-submission race dan regression test.
- Minggu 2: model arena dengan task, fixture, dan rubric identik.
- Minggu 3: prompt-injection fixture dan permission gate.

Branch `week-XX-start` memang merah. Selesaikan task dan kumpulkan evidence sebelum membuka `week-XX-solution`.
