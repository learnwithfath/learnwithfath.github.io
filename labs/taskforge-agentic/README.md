# TaskForge Agentic Starter

Local-first starter monorepo untuk Minggu 4–24. Source ini menunjukkan checkpoint solution terakhir; clone `taskforge-agentic.bundle` untuk branch mingguan.

Surfaces: Go, NestJS adapter, Next.js, Nuxt, Flutter, Android Compose, dan SwiftUI. PostgreSQL serta Redis berjalan melalui Docker Compose. Semua layanan eksternal lain menggunakan simulator lokal.

```bash
npm run test:smoke
npm run lab -- verify 04
```
