## Commands

```bash
npm run dev           # start local site at http://localhost:9090
npm run stop          # stop the background server
npm run new           # scaffold a new codelab Markdown template
npm run export        # export all codelabs/*.md → codelabs/<slug>/index.html via claat
npm run export:single -- <file>.md  # export one source (run from repo root, not codelabs/)
npm run build         # export + validate roadmap JSON + validate lab acceptance packs
npm run generate:labs # regenerate acceptance packs and Git bundles from roadmap data
npm run validate:roadmap  # validate codelabs/data/agentic-roadmap.json
npm run validate:labs     # validate generated lab acceptance packs and bundles
```

**Prerequisites:** Go must be installed (`claat` is fetched via `go run` on first use).

## Architecture

### Content pipeline

`codelabs/<slug>.md` (source) → `claat export` → `codelabs/<slug>/` (generated HTML + `codelab.json`). The catalog landing page (`codelabs/index.html`) reads `codelabs/data/codelabs.json` for card metadata and `codelabs/data/agentic-roadmap.json` for the 24-week agentic engineering roadmap.

The roadmap JSON is the **data backbone** for several derived artifacts:
- `scripts/validate-agentic-roadmap.mjs` — asserts 8 phases, 24 weeks, required tracks, and that each phase has a paired source `.md` and generated `index.html`.
- `scripts/generate-agentic-labs.mjs` — reads roadmap weeks and emits per-week acceptance packs under `labs/agentic-loop-lab/acceptance/` (weeks 1–3) and `labs/taskforge-agentic/acceptance/` (weeks 4–24), plus two Git bundles at `codelabs/downloads/*.bundle`.
- `scripts/validate-agentic-labs.mjs` — verifies each acceptance pack has `manifest.json`, `fixture.json`, `expected-output.txt`, `README.md`, and that both bundles contain the correct `week-NN-start` / `week-NN-solution` branches.

### Lab structure

Each lab (`labs/agentic-loop-lab`, `labs/taskforge-agentic`) is a standalone Git-bundled workspace. Learners clone from the bundle, switch to a `week-NN-start` branch, implement the task, run the verifier (`npm run lab -- verify NN`), and compare against `week-NN-solution`. Evidence files (`evidence/week-NN.txt`) are intentionally absent on start branches.

### Catalog JS/CSS

`codelabs/js/` and `codelabs/css/` contain shared frontend code for the catalog page (`SearchController`, pagination, filter chips). These files are **not** generated by claat — edit them directly when changing catalog behavior.
