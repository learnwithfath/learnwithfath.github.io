SEBELUM MULAI

Cek prasyarat sebelum minggu pertama

Untuk siapa

Engineer yang sudah sesekali pakai Claude, Codex, atau Gemini secara manual—buka sesi, jelaskan bug, agent kerjain, deploy, selesai—dan ingin naik level ke sistem yang tidak tergantung satu model frontier, bisa dioperasikan dari HP, dan efisien dalam token. Alokasikan 15–20 jam / minggu selama 24 minggu.

Prasyarat toolchain

Go ≥ 1.22 · Node.js ≥ 20 · Docker ≥ 24 · Git ≥ 2.40. Untuk mobile: Flutter ≥ 3.19, Android Studio / Xcode terbaru. Coding-agent host (Claude Code, Qwen Code, atau kompatibel) sudah terinstall dan bisa menjalankan perintah terminal.

Akses model & biaya

Siapkan akses ke minimal satu model Barat dan satu model Tiongkok. Model frontier ditagih per token — gunakan gateway seperti OpenRouter atau KeiRouter untuk memusatkan credential dan memantau budget. Catat biaya per run di model-scorecard.tsv sejak Minggu 2.

Aset & lab

Semua template tersedia di agentic-engineering-assets/ (lihat Toolkit di bawah halaman ini). Lab mingguan diunduh sebagai Git bundle — clone, switch ke branch week-NN-start, lalu jalankan verifier npm run lab -- verify NN.
